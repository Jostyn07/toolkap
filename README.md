# Toolkap

Página principal de Toolkap. Next.js 16 + React 19 + Tailwind CSS 4.

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # compilación de producción
```

## Dónde editar

- `lib/site.ts`: correo, número de WhatsApp, Facebook y dominio.
- `lib/content.ts`: textos y precios de servicios, productos, cotizador y proceso.
- `app/globals.css`: colores, fuentes y facetas de la marca.
- `public/products/`: capturas reales de Xiris, CrediPro y Fincil.cloud.
